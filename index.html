FlowBell

Browser-Based Hourly Chime Clock · Personal Project · 2026
Live Now ↓

A free browser tool that chimes every hour and half hour — built because I couldn't find anything that did this simple thing well.

Web Audio API Vanilla JS localStorage Deep Work Productivity Open Source
The Problem

I get deeply absorbed in work — which is great for output, but terrible for time. I'd sit down to work on something for 30 minutes and look up to find two hours had passed. I wanted something passive: no timers to set, no alarms to dismiss, just a quiet bell in a browser tab that rings every hour and half hour like a clock tower in the background.

I looked everywhere. Nothing matched. Most tools were too complex, required installs, or had friction. So I built it myself with AI assistance — and it's been running on my laptop ever since.

What I Built
Zero Install Runs in any browser tab
Smart Schedule Silences during sleep hours
Free Forever · Ko-fi for support
1 file Pure HTML · No dependencies
Why It Matters

This is not a showcase project — it's a tool I actually use every day. It reflects how I think: identify a real friction, look for existing solutions, and if none exist, build the simplest possible version that solves the problem. Shipped in a weekend using AI-assisted development. Hosted, indexed, and live at a custom domain.
